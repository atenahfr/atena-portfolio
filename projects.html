Undergraduate Thesis · Usable Security · In Progress

Making the Secure Path the Trivial Path — Interaction Design for Threshold Signatures

Threshold signature schemes like FROST, Arctic, and Threshold Raccoon are evaluated only on cryptographic grounds: can an attacker forge a signature? Nobody asks whether the humans acting as signers can operate them correctly. This research applies Ka-Ping Yee's ten principles of secure interaction design to the moments where a plausible interface would lead a signer to break the scheme's security assumptions, such as missing an aborted co-signer, trusting the wrong majority, or reusing session state, with no flaw in the cryptography. The goal is a set of concrete design guidelines, supervised by Dr. Navid Nasr Esfahani.

Database Systems · Team Project

Clothing Retail Store DBMS — Oracle Database Design & Application

A relational database for a three-floor clothing store, designed end to end in Oracle by a team of three: ER and EER models, a ten-table schema that enforces the business rules in the database itself, normalization to 3NF/BCNF, views and advanced SQL, and a Unix shell menu application that runs the queries. Its core idea is the product-versus-variant split: stock is counted, sold, and returned per size, never per design.

Academic Research · SPyCy Lab, TMU · In Progress

Blueberry — Distributed Encrypted File Storage

A SPyCy Lab research project at Toronto Metropolitan University, built under Professor Navid Nasr Esfehani: a distributed file storage system in Rust that splits files into encrypted shares and spreads them across Amazon S3, Google Drive, and Dropbox, so no single provider — or single point of compromise — ever holds a complete copy. I designed the dashboard UI in Figma, defined the acceptance criteria driving the frontend build, and am now building that frontend layer in Dioxus.
